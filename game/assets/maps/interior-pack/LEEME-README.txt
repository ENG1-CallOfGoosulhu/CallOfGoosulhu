🎨 Formato:
- Resolución: 32x32 píxeles por tile

- Formato de archivo: PNG

📦 Contenido:

===========================================
🏪 Storefront Interior
Pixel Art Asset Pack by k0mbuch.art
===========================================

🎨 Format:
- Resolution: 32x32 pixels per tile
- Style: Top-down
- File format: PNG
- Compatible with any 2D engine (Godot, Unity, etc.)

📦 Included:
- Counter
- Cash register
- Empty shelves (front and side view)
- Refrigerated display cases
- Center aisle displays
- Crates with fruits and vegetables
- Cardboard boxes
- Bottles
- Wooden floor
- Example mockup (with integrated shadows)

🛠 Usage notes:
- Furniture is meant to be placed on a 32x32 tile grid
